# 사전 신청을 구글 스프레드시트로 받기 (10분)

지금은 신청이 아무 곳에도 저장되지 않습니다(데모 모드).
아래를 따라 하면 신청이 들어올 때마다 구글 시트에 한 줄씩 쌓입니다.

---

## 1. 시트 만들기

1. https://sheets.new 로 새 스프레드시트를 만들고 이름을 `그립나우 사전신청` 으로 바꿉니다.
2. **첫 줄(1행)에 아래 제목을 왼쪽부터 순서대로** 입력합니다. 순서가 중요합니다.

```
접수시각	이름	연락처	이메일	브랜드	방송채널	월매출	유입경로	이전페이지	신청페이지
```

---

## 2. 앱스 스크립트 붙이기

1. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 원래 있던 코드를 전부 지우고, 아래를 그대로 붙여넣습니다.

```javascript
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  const d = JSON.parse(e.postData.contents);
  sheet.appendRow([
    d.receivedAt || new Date().toISOString(),
    d.name || '',
    d.phone || '',
    d.email || '',
    d.brand || '',
    (d.channels || []).join(', '),
    d.scale || '',
    d.source || '',
    d.referrer || '',
    d.page || ''
  ]);
  return ContentService
    .createTextOutput(JSON.stringify({ ok: true }))
    .setMimeType(ContentService.MimeType.JSON);
}
```

3. 저장(디스켓 모양 또는 Ctrl+S).

---

## 3. 주소 만들기 (배포)

1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴(유형 선택) → **웹 앱** 을 고릅니다.
3. 이렇게 설정합니다.
   - 설명: 아무거나 (예: `그립나우 신청 접수`)
   - **다음 사용자로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**  ← 이걸 안 바꾸면 신청이 안 들어옵니다
4. **배포** 를 누르고, 구글이 권한을 물으면 허용합니다.
   (`이 앱은 확인되지 않았습니다` 가 나오면 → 고급 → 안전하지 않은 페이지로 이동)
5. 마지막에 나오는 **웹 앱 URL** 을 복사합니다.
   `https://script.google.com/macros/s/AKfycb....../exec` 모양입니다.

---

## 4. 그립나우 사이트에 주소 알려주기

터미널(PowerShell)에서 프로젝트 폴더로 가서 아래를 실행합니다.

```bash
cd "C:\Users\grip_301\Desktop\AI 프로덕트\그립나우랜딩"
```

그다음 이 명령을 실행하고, 물어보면 3번에서 복사한 URL을 붙여넣습니다.

```bash
vercel env add LEAD_WEBHOOK_URL production
```

마지막으로 다시 배포하면 끝입니다.

```bash
vercel --prod
```

---

## 5. 확인

사이트에서 본인 이름·번호로 한 번 신청해 보고, 시트에 한 줄이 생기는지 봅니다.
안 생기면 3번의 **"액세스 권한이 있는 사용자: 모든 사용자"** 를 다시 확인하세요. 여기가 제일 자주 틀립니다.

---

## 참고

- 웹 앱 URL은 비밀입니다. 이 주소를 아는 사람은 시트에 줄을 추가할 수 있으니 공개된 곳에 올리지 마세요.
  (그래서 브라우저가 아니라 서버에만 두었습니다 — 방문자에게는 보이지 않습니다.)
- 앱스 스크립트 코드를 고치면 **배포 → 배포 관리 → 수정 → 새 버전 → 배포** 를 해야 반영됩니다.
