# 사전 신청을 구글 스프레드시트로 받기

신청이 들어올 때마다 구글 시트에 한 줄씩 쌓이게 만드는 방법입니다.

**받는 시트**: [그립나우 사전신청](https://docs.google.com/spreadsheets/d/1GKa9ExwkkgkyrQWEH2K94xUdZr2tU-gkTRD-zm1qzh8/edit)
(제목 줄 10칸은 이미 넣어뒀습니다. 순서를 바꾸면 아래 스크립트도 같이 고쳐야 합니다.)

```
접수시각  이름  연락처  이메일  브랜드  방송채널  월매출  유입경로  이전페이지  신청페이지
```

## 1. 앱스 스크립트 붙이기 (브라우저)

1. 위 시트를 열고, 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 원래 있던 코드(`function myFunction() {}`)를 전부 지우고, 아래를 그대로 붙여넣습니다.

```javascript
// 그립나우 랜딩 → 이 시트로 신청을 받는 창구
function doPost(e) {
  // 동시에 두 건이 들어와도 줄이 섞이지 않게 잠금
  const lock = LockService.getScriptLock();
  try {
    lock.waitLock(30000);
  } catch (err) {
    return json({ ok: false, error: 'busy' });
  }

  try {
    const d = JSON.parse(e.postData.contents);

    // 같은 신청이 두 번 오면(전송 재시도) 무시 — 중복 행 방지
    const cache = CacheService.getScriptCache();
    const key = d.leadId ? 'lead_' + d.leadId : null;
    if (key && cache.get(key)) {
      return json({ ok: true, duplicate: true });
    }

    const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
    sheet.appendRow([
      d.receivedAt ? new Date(d.receivedAt) : new Date(),
      d.name || '',
      d.phone || '',
      d.email || '',
      d.brand || '',
      (d.channels || []).join(', '),
      d.scale || '',
      d.source || '',
      d.referrer || '',
      d.page || ''
    ]);

    if (key) cache.put(key, '1', 21600); // 6시간 동안 기억

    return json({ ok: true });
  } catch (err) {
    return json({ ok: false, error: String(err) });
  } finally {
    lock.releaseLock();
  }
}

// 브라우저로 주소를 열었을 때 "살아있는지" 확인용
function doGet() {
  return json({ ok: true, message: 'gripnow lead endpoint is alive' });
}

function json(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
```

3. 저장합니다. (디스켓 모양 또는 Ctrl+S)

---

## 2. 주소 만들기 (배포)

1. 오른쪽 위 **배포 → 새 배포**.
2. 왼쪽 톱니바퀴(유형 선택) → **웹 앱**.
3. 이렇게 맞춥니다.
   - 설명: 아무거나 (예: `그립나우 신청 접수`)
   - **다음 사용자로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**  ← 여기가 제일 자주 틀립니다
4. **배포** → 구글이 권한을 물으면 허용합니다.
   (`이 앱은 확인되지 않았습니다` 가 나오면 → **고급** → **안전하지 않은 페이지로 이동**)
5. 마지막에 나오는 **웹 앱 URL** 을 복사합니다. 이 모양입니다.

```
https://script.google.com/macros/s/AKfycb....../exec
```

### 잘 됐는지 바로 확인하는 법
복사한 주소를 브라우저 주소창에 그대로 붙여 엽니다.
`{"ok":true,"message":"gripnow lead endpoint is alive"}` 가 보이면 성공입니다.

- 로그인 화면이 뜨거나 권한 오류가 나면 → 3번의 **"액세스 권한이 있는 사용자: 모든 사용자"** 를 다시 확인하세요.

## 시트 시간대

이 시트는 API 로 만들어져서 시간대가 **미국 태평양**으로 잡혀 있습니다. 한 번만 바꿔주세요.

**파일 → 설정 → 시간대 → (GMT+09:00) 서울 → 설정 저장**

바꾸면 이미 쌓인 줄들도 한국 시간으로 다시 표시됩니다.

## 참고

- **웹 앱 URL은 비밀입니다.** 이 주소를 아는 사람은 시트에 줄을 추가할 수 있으니 공개된 곳에 올리지 마세요.
  그래서 브라우저가 아니라 Vercel 서버에만 넣어뒀습니다 — 사이트 방문자에게는 보이지 않습니다.
- **스크립트를 고쳤으면 반드시 재배포해야 반영됩니다.**
  `배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포`
  이 방식은 **주소가 그대로**입니다. "새 배포"를 또 만들면 주소가 바뀌어서 3번을 다시 해야 합니다.
- 재시도로 같은 신청이 두 번 와도 `leadId` 를 6시간 기억해서 중복 행을 만들지 않습니다.
- 전송이 실패하면 신청자에게 "계속 안 되면 rayyun@gripcorp.co 로 연락 주세요" 문구가 뜨고,
  실패한 신청 내용은 Vercel 서버 로그에 남습니다. (Vercel → 프로젝트 → Logs)
